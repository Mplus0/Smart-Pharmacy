# 单车网页控制台（第一版）

独立辅助工具，不修改原业务节点、三个操作脚本、配置及 launch。
仅适用于可信局域网；不提供用户登录，不应映射到公网。

## 车辆端启动

```bash
python3 ~/robot_ws/src/pharmacy_ISCC/tools/web_console/server.py
```

电脑或手机连接同一网络后打开 `http://小车IP:8090`，当前 Car 1 配置地址为
`http://192.168.124.20:8090`。端口可通过 `--port 8090` 设置。
后台需要 Python 3.6+，只使用标准库，无额外 pip 依赖。ROS 订阅使用独立进程，默认
运行 source 工作空间后的 `python`，兼容 Melodic 的 Python 2 rospy；若板端 ROS
安装在 Python 3，传 `--ros-python python3`。不要安装不同 Python 版本的 rospy 来混用。

1. 点击“启动环境”：调用相邻的 prepare_race.sh，启动基础及业务节点。
2. 日志提示等待手动启动、人工确认定位后，点击“开始比赛”。以服务的 success 为准。
3. 点击“全部停止”：调用 stop_race.sh，请求关闭两个 launch，网页后台仍然运行。

使用网页期间不要再用终端重复启动同名节点。第一版进程状态跟踪的是本后台启动的
准备脚本，不能完整接管后台启动前已有的进程；需要先用 stop_race.sh 停止旧环境。
后台重启不会自动恢复比赛放行时间，也不会自动发放行命令。
关闭浏览器不停止车辆。关闭后台也不会主动停止车辆；此时可在终端执行 stop_race.sh。
“全部停止”不是硬件急停。界面仅在脚本退出后显示退出，不把停止命令返回等同于底盘已停稳。

## 数据和开销

- ros_observer.py 只订阅 /nav_state、/cam_return、/board2_return，每 2 秒检查 ROS 服务注册。
  不发布消息、不改变业务状态。不以 /dual_car/round_done 判断比赛完成（该话题用于令牌释放）。
- 观察程序随环境启动，未连接到 ROS 时页面继续可用，服务未就绪时不允许网页放行。
- 页面每秒读取后台缓存；ROS 状态超过 6 秒未更新即标为失效。
- 识别结果显示原始整数数组和接收时间，避免未经验证的业务字段解释。
- 视频默认关闭，直接连接当前网页主机的 8080 /stream?topic=/camera/rgb/image_raw，
  与现有 Car 1 配置对应。新窗口会产生独立视频连接，需单独关闭。
- 日志仅保留最近 1200 条、每条最多 2000 字符；下载内容也是该缓存，不是全部 ROS 历史日志。
- 三个操作固定映射脚本；后台拒绝重复操作，POST 使用会话令牌，页面禁止 iframe 嵌入。
  令牌用于防止跨站误调用，并非用户身份认证。
- 按钮操作期间暂不可重复操作；放行命令最长等待 20 秒，超时标为结果未知，不自动重试。

## 验证边界

开发机遵循包内 AGENTS.md，只完成源码静态检查，未运行服务器、浏览器、Python 编译、
ROS 或实车测试。板端尚需验证：启动与停止、重复点击、服务拒绝、断网与重连、视频开关、
ROS 解释器匹配、进程退出行为及负载。第一版不包含双车、地图、遥控或暂停恢复。
